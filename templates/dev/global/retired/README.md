# global/retired/ — 퇴역한 단위

> `dev/global/`에서 **제거·대체된 단위**를 보관하는 곳이다. 현역 설계가 아니다 — 현재 설계는 `../map.md`와 개념 문서에 있다.
> 승격 절차 2번에서, 사이클 `design/map.md`의 "global 관계"가 `제거: <ID>` 또는 `대체: <옛 ID> → <새 ID>`인 단위를 이곳으로 옮긴다.

## 규칙
- 파일 이름: `YYYY-MM-DD-<개발 코드>.md` — 퇴역시킨 승격의 날짜와 사이클 코드. 한 승격에서 여러 단위가 퇴역하면 한 파일에 모은다.
- 옮기는 것은 **그 단위의 global map 행과 그 단위에 대한 서술뿐**이다. 같은 개념 문서의 현역 단위 서술은 그대로 둔다.
- 옮긴 뒤 `../map.md`의 "퇴역 단위" 목록에 파일 링크를 추가하고, 퇴역한 ID를 `dev/`·`project-memory/` 전체에서 grep해 인용처를 갱신한다.
- **퇴역한 ID는 다시 쓰지 않는다.**

## 파일 형식
~~~
# YYYY-MM-DD <개발 코드> 승격으로 퇴역한 단위

- 제거일: YYYY-MM-DD
- 사유: <한 줄>
- 대체 단위: <새 단위 ID — 제거만이면 "없음">
- 사이클: [`dev/<개발 코드>/`](../../<개발 코드>/README.md)

## <단위 ID> <단위 이름>
<옮겨 온 global map 행>

<옮겨 온 서술>
~~~
