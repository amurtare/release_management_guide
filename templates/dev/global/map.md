# global/map.md — 설계 지도 (as-is, 완료된 것까지)

> 행은 승격 때 사이클의 `design/map.md`에서 반영한다. 사이클 밖 작업이 서술을 바꾸면 같은 커밋에서 갱신한다. 사이클 밖에서 생긴 단위의 ID는 `GLOBAL-U<n>`이고, 이 지도에서 이어 번호를 매긴다.
> `(워크플로형)` 열은 워크플로형 프로젝트에서만 쓴다. 병렬 단위(엔드포인트 등)로 이뤄진 서비스·라이브러리형은 두 열을 지우고 의존 관계만 적는다.
