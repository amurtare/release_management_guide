# dev — 진입점

> 첫 줄의 `<!-- rmg: dev-cycles -->`는 훅이 이 프로젝트를 8단계 사용 프로젝트로 알아보는 표식이다 — 지우거나 첫 줄에서 옮기지 않는다.
> 한 번에 한 사이클만 진행한다. 새 사이클은 진행 중 사이클이 승격·폐기된 뒤에만 시작한다.
> 이 표는 사이클 시작·승격·폐기 때만 갱신한다(기본 브랜치 커밋, 사용자 허락). 현재 단계는 각 사이클 README에 있다.
> 세션 시작 훅(`session_start_brief`)이 이 표의 `진행 중` 행을 읽는다 — 아래 예시는 코드블록 안에 두었으니 표에 옮길 때만 쓴다.

## 사이클
| 코드 | 이름 | 상태 | 브랜치 | 시작일 | 완료일 |
|---|---|---|---|---|---|

상태: `진행 중` / `승격 완료` / `폐기`

예시(행을 이 형식으로 위 표에 추가한다):
```
| AUTH | 로그인·권한 | 진행 중 | cycle/AUTH | YYYY-MM-DD | |
| SHOP | 상점 | 폐기 | (archive/SHOP) | YYYY-MM-DD | YYYY-MM-DD — <사유 한 줄> |
```

## 승격 완료
- `<코드>` — YYYY-MM-DD 승격 — <한 줄 요약> — 반영 문서: `global/<…>`

## global
`global/` — 기본 브랜치에 반영된 현재 설계(승격된 사이클 + 사이클 밖 작업까지. overview · map · 개념 설계). 개발 코드 `global`은 예약어다.
