# <코드> Plan 체크리스트

## 역전파 체크리스트 (매번 복사해서 사용)

단위를 상세화할 때뿐 아니라 확정 항목의 상태·성격을 바꿀 때도 매번 복사해 체크한다.

- [ ] 이 변경으로 바뀐 결정이 있는가? (없으면 종료)
- [ ] **★ 식별자 grep 역전파** — 바꾼 단위·항목의 ID와 관련 파일명을 `dev/<코드>/`·`project-memory/` 전체에서 grep해 **인용처를 빠짐없이 갱신**한다. 가장 잘 빠지는 곳: 다른 설계 문서의 상호 참조, ID를 나열한 요약 표
- [ ] 사이클 설계 지도(`../design/map.md`)의 해당 행 한 줄 요지 갱신(또는 "변경 없음" 확인)
- [ ] `overview.md`의 확정 사실·전제에 영향이 있는가
- [ ] 해당 단계 `open-questions.md`의 해소·신규 발생 반영(건수 표기 포함)
- [ ] 설계 지도의 "참조" 칸이 실제 문서를 정확히 가리키는가

대체 표식: `dev/` 문서(plan·design·global) 본문에서 결정이 뒤집히면 옛 서술을 지우지 말고
`~~옛 서술~~ [대체됨 YYYY-MM-DD: 새 내용 — 링크]`로 남긴다. **`project-memory/decisions/`에는 대체 표식을 쓰지 않는다** — 결정 파일 본문은 수정하지 않고, 뒤집히면 새 결정 파일 + `Superseded by` 연결.
단, global에서 **제거·대체된 단위**는 대체 표식 대신 `dev/global/retired/`로 이동한다(승격 절차). 이동하는 것은 그 단위의 행·서술뿐이고 현역 단위 서술은 그대로 둔다.
